# 삼부자중기 공식 홈페이지

서울·경기 지역을 중심으로 스키드로더, 바브캣 등 건설중장비 작업 및 임대 서비스를 소개하는 삼부자중기 공식 홈페이지입니다.

## 주요 서비스

- 스키드로더 작업
- 바브캣 임대
- 아스콘 및 건설 현장 작업
- 소규모 현장 대응
- 장기·단기 작업
- 서울·경기 지역 출장
- 견적 문의 및 전화 상담

## 기술 스택

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## 로컬 실행

프로젝트를 내려받은 뒤 아래 명령어를 실행합니다.

```bash
npm install
npm run dev
npm run build
